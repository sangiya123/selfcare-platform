# Android Setup

This directory is generated by React Native CLI. To set up the Android project:

```bash
cd selfcare-app
npx react-native init selfcareSelfcare --directory android
# OR use the existing android/ folder and run:
cd android
./gradlew assembleDebug
```

## Key files

- `app/src/main/AndroidManifest.xml` — permissions, deep-link scheme (`selfcare://`)
- `app/build.gradle` — app ID (`com.selfcare.selfcare`)
- `app/src/main/res/values/strings.xml` — app display name
- `keystores/debug.keystore` — debug signing key (replace for release)

## Build

```bash
# Debug APK
./gradlew assembleDebug

# Release APK (requires signing config)
./gradlew assembleRelease
```

## Bundle JS into APK (offline support)

```bash
cd ..
npx react-native bundle \
  --platform android \
  --dev false \
  --entry-file index.js \
  --bundle-output android/app/src/main/assets/index.android.bundle \
  --assets-dest android/app/src/main/res

# Then rebuild
cd android && ./gradlew assembleRelease
```
