# iOS Setup

This directory is generated by React Native CLI. To set up the iOS project:

```bash
cd selfcare-app
npx react-native init selfcareSelfcare --directory ios
# OR use CocoaPods with existing ios/ folder:
cd ios
pod install
```

## Key files

- `selfcareSelfcare/Info.plist` — URL scheme (`selfcare://`), app display name
- `selfcareSelfcare.xcodeproj` — Xcode project
- `selfcareSelfcare.xcworkspace` — workspace after `pod install`
- `selfcareSelfcare/AppDelegate.mm` — app delegate (deep-link handling)

## Build

```bash
# Open in Xcode
open selfcareSelfcare.xcworkspace

# Or via CLI
xcodebuild -workspace selfcareSelfcare.xcworkspace \
  -scheme selfcareSelfcare \
  -configuration Debug \
  -destination "platform=iOS Simulator,name=iPhone 15" \
  build

# Release (requires signing certificate + provisioning profile)
xcodebuild -workspace selfcareSelfcare.xcworkspace \
  -scheme selfcareSelfcare \
  -configuration Release \
  -archivePath build/selfcareSelfcare.xcarchive \
  archive
```

## Bundle JS for Release

```bash
cd ..
npx react-native bundle \
  --platform ios \
  --dev false \
  --entry-file index.js \
  --bundle-output ios/main.jsbundle \
  --assets-dest ios
```
