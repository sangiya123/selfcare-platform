# iOS Setup

This directory is generated by React Native CLI. To set up the iOS project:

```bash
cd selfcare-app
npx react-native init OmobioSelfcare --directory ios
# OR use CocoaPods with existing ios/ folder:
cd ios
pod install
```

## Key files

- `OmobioSelfcare/Info.plist` — URL scheme (`omobio://`), app display name
- `OmobioSelfcare.xcodeproj` — Xcode project
- `OmobioSelfcare.xcworkspace` — workspace after `pod install`
- `OmobioSelfcare/AppDelegate.mm` — app delegate (deep-link handling)

## Build

```bash
# Open in Xcode
open OmobioSelfcare.xcworkspace

# Or via CLI
xcodebuild -workspace OmobioSelfcare.xcworkspace \
  -scheme OmobioSelfcare \
  -configuration Debug \
  -destination "platform=iOS Simulator,name=iPhone 15" \
  build

# Release (requires signing certificate + provisioning profile)
xcodebuild -workspace OmobioSelfcare.xcworkspace \
  -scheme OmobioSelfcare \
  -configuration Release \
  -archivePath build/OmobioSelfcare.xcarchive \
  archive
```

## Bundle JS for Release

```bash
cd ..
npx react-native bundle \
  --platform ios \
  --dev false \
  --entry-file index.js \
  --bundle-output ios/main.jsbundle \
  --assets-dest ios
```
